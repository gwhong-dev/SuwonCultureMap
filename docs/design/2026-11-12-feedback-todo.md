## 4. 겹침 주의 (참고)

- `js/index.js` · `css/index.css` 두 파일에 화면 코드가 몰려 있음 → **같은 영역을 고치는 묶음은 차례**(B → E · I), 영역이 떨어진 묶음(A · B · C · F)은 병렬 후보
- 새 코드는 가능하면 새 파일로 빼고 `index.js` 는 연결만 → 파일 끝에 덧붙여 생기는 충돌 방지
- A 가 머리글의 회원 표시를 바꾸고 H 가 그 자리에 닉네임을 넣음 → H 는 A 머지 뒤
- 움직임(마커 튀어오름 · 인트로)은 `prefers-reduced-motion`(움직임 줄이기 설정)이면 생략
