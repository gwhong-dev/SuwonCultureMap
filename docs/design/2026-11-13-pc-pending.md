## ① 상세 칸

### R1 B — 포스터 칸 4:3 고정 + ‹ › 는 포스터 아래 줄

근거(11/13 운영 행사 147개 이미지 측정): 재단(SWCF) 121개 **전부 530×400(4:3)**, 인스타 26개 중 11개 1080×1350(4:5) · 15개 사진 없음 → 82%가 4:3.

- 포스터 칸: **400×300 고정**(상세 칸 폭 440 − 안쪽 여백 20×2, 비율 4:3 = `aspect-ratio: 4 / 3`), 지금의 "남는 높이 채우기(flex: 1, 최소 240px)" 를 없앤다 → 모니터 높이와 상관없이 정보가 늘 같은 자리
- 이미지 `object-fit: contain` + 바탕 `--surface` 그대로 (재단 4:3 은 꽉 참, 인스타 4:5 는 가운데 240×300)
- 사진 없는 행사 기본 그림(`default-poster`): 같은 400×300 안에서 **분류 글자 위 왼쪽(22px 24px) → 제목 그 아래 20px 간격, 위쪽 정렬(세로 가운데 아님)** → 장소는 맨 아래 왼쪽. 제목 26px 고운바탕 700 · 줄 간격 1.35, 칸을 넘으면 3줄에서 말줄임
- 포스터 위 `1 / 30` 알약과 ‹ › 단추는 **포스터 밖으로** — 포스터 바로 아래 높이 40px 줄: 왼쪽 ‹ · 가운데 `1 / 30`(13px · 700 · `--sub`) · 오른쪽 ›
  - 위치 점(`pcdDots`)은 없앤다 (줄의 `1 / 30` 이 대신함)
- 그 아래 순서 그대로(간격 14px): 배지 → 제목 21px → 기간 · 장소 · 출처 → 단추 줄 44px → 나머지 정보(스크롤) / 맨 아래 키 표시 줄 고정
- 1440×900 · 1280×800 둘 다 첫 화면에 단추 줄까지 보여야 함

### R2 — ‹ › 단추 모양 고정

- 늘 같은 모양: 40px 원, 바탕 `--bg`, 테두리 1px `--line`, 그림자 `0 1px 4px rgba(0,0,0,.18)`, 글자 20px `--text`
- 마우스 올림: 바탕 `--surface`, 테두리 `--line-strong`
- 처음 · 끝(`aria-disabled="true"`): **원 · 테두리 · 그림자는 그대로, 화살표 글자만 `--line-strong`(#c9c3ba)**. 지금처럼 단추 전체 `opacity: 0.4` 를 쓰지 않는다 (사진 위에서 안 보였던 원인 — 찜 여부와는 관계없음)
- 키보드 포커스: 2겹 고리 그대로(`0 0 0 2px var(--bg), 0 0 0 4px var(--text)`)

### R3 A — 툴팁 밝고 짧게

- 글: `이전 [←]` · `다음 [→]` (짧은 새 i18n 키, 4개 언어). `aria-label` 은 지금처럼 "이전 행사" · "다음 행사"
- 모양: 바탕 `--bg`, 테두리 1px `--line`, 반지름 6, 안쪽 3px 7px, 12px `--text`, 그림자 `0 2px 6px rgba(0,0,0,.10)`; 키캡 테두리 1px `--line-strong` · 반지름 3 · 11px `--sub`
- 자리: **단추 가로 가운데**(`left: 50%; transform: translateX(-50%)`), 단추 위 6px
- 동작 그대로: 마우스를 올리면 뜸 · 툴팁 위로 옮겨도 유지 · Esc 로 닫힘 (WCAG 1.4.13), 키 표시 줄은 그대로 둠

- PC 상단 바에서 검색창을 뺀다 (상단 바 = 로고 | 오른쪽 언어 · ☾ · 로그인 · ☰). 모바일 검색은 그대로

  - 입력칸 높이 44px, 반지름 8, 테두리 1px `--line`(포커스 · 글자 있음 1.5px `--text`), 바탕 `--bg`, 15px, 왼쪽 돋보기 20px(왼쪽 12px), 안쪽 왼쪽 40px

### R7 — 먼 행사로 갈 때 축소 → 이동 → 확대

- 목록 · ‹ › · 검색으로 고른 행사가 **지금 화면 밖이고, 지금 화면 한 칸 넘게 떨어져 있을 때만**
  1. 지금 자리에서 레벨 +2 (250m → 1km 정도) `animate`, 0.3초
  2. 축소한 채 `panTo` 새 행사, 0.4초
  3. 원래 레벨로 `animate`, 0.3초 — 고른 핀 크게(지금 선택 표시 그대로)
- 화면 안이거나 바로 옆이면 지금처럼 `panTo` 만
- 이동 중 다른 행사를 고르면 남은 단계는 버리고 새 행사로 다시 시작
- `prefers-reduced-motion: reduce` 면 `setCenter` 로 한 번에
