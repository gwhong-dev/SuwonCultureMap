# P3 끝 넘김 개선 — 확정 시안 (11/16)

- 캔버스: [P3 끝 넘김 개선 시안](https://claude.ai/artifact/7sxZaXmJUjyxz2ys7SvgUB) (비공개, 참고용) — 개발 기준 아트보드 **'이어 보기'**(`Flow.dc.html`)
- 계기: 11/14 사용자 아이폰 확인 (P3 #240) — "더 밀면 전체" 문구를 간결하게, 지도로 넘어갈 때 지도 배경을 불러오는 동안 보여 줄 전환 화면 필요
- 결정 흐름: 끝 안내 레이아웃 A(세로) · B(가로 두 줄) → **B**. 문구 후보 4개 → **'넘기면 지도로'**. 전환 A(종이색 덮개) · B(카드 줄 먼저) → A, A 속도 변주 A1 흐려짐 · A2 당긴 방향 · A3 핀에서 펼침 → **A3** (당김이 이미 가로 움직임이라 가로를 두 번 겹치지 않음, 핀 → 지도로 이어짐)

## ① 끝 안내 (홈 '지금 진행 중' 카드 줄 끝)

| 항목 | 값 |
|---|---|
| 폭 | 52px (지금과 같음), 바탕 없음, 벽돌 글자(`--accent-ink`) |
| 모양 | 화살표(20px) 아래 **가로 두 줄** 글자 12px · 500 · 줄 간격 1.35 · 가운데. 세로 글자(`writing-mode`) 없앰 |
| 문구 | ko "넘기면 지도로" · en "Swipe to map" · ja "めくって地図へ" · zh "滑动看地图" |
| 누르기 · 키보드 | 지금과 같음 (버튼 → 지도 탭 + 진행 중) |

## ② 당김 움직임 (끝에 닿은 채 왼쪽으로 한 번 더 당길 때)

| 항목 | 값 |
|---|---|
| 늘어나는 양 | 당긴 거리 p → `70 × (1 − e^(−p/70))` px (손을 따라가다 점점 무거워짐, 최대 약 70px) |
| 카드 줄 | 늘어난 양 × 0.6 만큼 왼쪽으로 |
| 끝 안내 칸 | 폭 52 + 늘어난 양 × 0.6 (오른쪽 끝은 제자리, 왼쪽으로 넓어짐) |
| 화살표 | 늘어난 양 × 0.35 만큼 오른쪽으로 |
| 기준 | 40px (지금 `HOME_END_SWIPE_PX` 그대로). 넘으면 화살표 1.15배 + 문구 **"놓으면 지도로"** (en "Release for map" · ja "離すと地図へ" · zh "松开看地图") |
| 놓기 | 기준 넘음 → 지도로 (③). 덜 당김 → 제자리로 260ms `cubic-bezier(0.2, 0.8, 0.2, 1)` |

## ③ 덮개 → 펼침 (지도 탭으로 넘어갈 때)

| 항목 | 값 |
|---|---|
| 언제 | 끝 당김 · 끝 안내 누르기로 지도로 갈 때, **이 페이지에서 지도 탭을 아직 안 열었을 때만** (이미 지도를 그렸으면 바로 지도) |
| 덮개 | 지도 자리 전체(하단 탭은 위에 그대로) 종이색 `--bar`, 0.14초에 나타남 |
| 내용 | 지도 핀(44px, 벽돌 선) — 위에서 12px 내려앉음 260ms `cubic-bezier(0.3, 1.4, 0.5, 1)` / 로고 워드마크 / "**N곳의 지도가 펼쳐지는 중**" 14px `--sub` (N = 홈 '지금 진행 중' 수). en "Opening the map of {n} places" · ja "{n}か所の地図を広げています" · zh "正在展开{n}处地点的地图" |
| 지도 준비 | 카카오 `tilesloaded` 또는 지도 타일 그림이 다 불러와짐(0.25초 뒤부터 확인), **늦어도 1.5초** |
| 펼침 (A3) | 핀 자리에서 원이 커지며 지도가 드러남. 420ms `cubic-bezier(0.55, 0, 0.25, 1)` (시안 480ms → 빨리 준비되면 느리게 느껴져 줄임, 운영에서 보고 조정). 핀 · 글자는 처음 150ms 에 흐려짐 |
| 움직임 줄이기 설정 | 당김 · 핀 움직임 없음, 펼침 대신 150ms 흐려짐 |
