# 모바일 앱식 레이아웃 — 디자인 확정안 v1

> 작성일: 2026-11-02
> 원본: Claude Design 캔버스 "수원바이블 모바일 1단계" (화면 7장 × 밝은/어두운). 이 문서는 캔버스를 코드로 옮길 때 기준이 되는 값만 정리한 것
> 근거: `docs/benchmark.md` (유사 앱 4개 비교 · 우선순위)
> 참고 소스: `design-source.zip` (캔버스 화면 원본, 값 확인용 — 그대로 복사해 쓰는 코드가 아님)

## 0. 적용 범위

- 대상: `src/main/resources/static/index.html` 의 **모바일 화면** (기존 `max-width: 1024px` 분기)
- PC 화면은 지금 레이아웃 유지
- 하단 탭: 디자인은 정적 버전 기준 4개(홈 · 지도 · 목록 · 찜). **Spring Boot 버전은 5번째 "마이" 탭 추가** (mypage.html 연결)

## 1. 디자인 값 (토큰)

| 이름 | 밝은 | 어두운 | 용도 |
|---|---|---|---|
| bg | `#FFFFFF` | `#141312` | 바탕 |
| surface | `#F4F2EF` | `#1E1C1A` | 회색 칸 (주소 박스 등) |
| line | `#E3DFD9` | `#35322E` | 구분선 · 테두리 |
| text | `#1C1B1A` | `#F2EFEA` | 본문 |
| sub | `#5F5A54` | `#A9A39B` | 보조 글자 |
| accent | `#B4472A` | `#E07A57` | 주 색 (화성 벽돌) · 버튼 · 선택 탭 |
| onAccent | `#FFFFFF` | `#141312` | 주 색 위 글자 |
| accentSoft / accentInk | `#F7E9E3` / `#93391F` | `#3A241C` / `#F0A285` | D-day 배지, 선택 칩 |
| blueSoft / blue | `#E6EEF6` / `#2D5B88` | `#1C2733` / `#8DB4DC` | 오픈예정 배지 |
| graySoft / gray | `#ECEAE6` / `#6B6660` | `#2A2825` / `#A9A39B` | 종료 배지 |

- 글꼴: `Noto Sans KR` (400 · 500 · 700), 대체 `Apple SD Gothic Neo`, `system-ui`
- 모서리: 0 ~ 2px (둥근 모서리 최소). 원형은 지도 숫자 클러스터만
- 그림자: 지도 위 떠 있는 카드에만 (`0 6px 18px rgba(0,0,0,.12)`)
- 누르는 영역: 최소 44 × 44px
- 어두운 테마: `prefers-color-scheme: dark` 를 따름 (토글은 나중)

## 2. 공통 부품

| 부품 | 규칙 |
|---|---|
| 상태 배지 | 운영중 = accent 바탕 / 오픈예정 = blueSoft 바탕 + blue 글자 / 종료 = graySoft 바탕 + gray 글자. **목록에서는 폭 고정**(56~64px)해 제목 시작선 맞춤. 상태 · D-day는 시작일 · 종료일로 계산 |
| D-day | 운영중 = "종료까지 D-N", 오픈예정 = "D-N"(시작까지) |
| 하단 탭 | 높이 64px, 아이콘 22px + 글자 11px. 선택 탭 = accent + 굵게 |
| 토스트 | text 바탕 + bg 글자, 높이 44~48px, 하단 액션바 위. 확인 버튼 없이 자동으로 사라짐. 찜("찜 목록에 담았어요 · 보기"), 주소 복사("주소를 복사했어요") |
| 행사 행 | 왼쪽 포스터 56×70 + 제목 15px + 보조 줄(분류 · 구 · 기간) + 배지. 홈 "곧 종료" · 검색 결과에서 같은 모양 |

## 3. 화면별

### 01 홈
- 헤더: 로고 자리(벽돌색 네모 + "수원바이블") · 검색 버튼 → 06 검색
- "11월 2일 – 8일 / 이번 주 수원 행사 **N개**"
- 포스터 캐러셀: 카드 280px, 다음 카드 살짝 보임, 진행 막대 + "1 / 5". **스와이프**로 넘김, 끝에서 처음으로(무한). 좌/우 버튼은 PC 너비에서만
- 날짜 칩: 오늘 · 이번 주말 · +7일
- "11월의 수원 행사" 가로 목록(카드 148px): **무한 반복 없이 끝에 "전체 보기 →" 카드**
- 곧 종료 / 곧 시작 탭 + 행사 행 3개 + D-day 배지
- 내 주변: 가까운 · 장안 · 권선 · 팔달 · 영통 칩 + 작은 지도 + "팔달구 행사 N개 · 지도에서 보기"

### 02 지도
- 상단: 검색창 + 필터 버튼, 분류 칩(전체 · 공연 · 전시 · 축제 · 교육)
- 마커: 벽돌색 네모, 선택된 마커는 포스터 썸네일 + 꼬리, 줌아웃 시 숫자 클러스터(원형)
- **첫 위치: 행궁동 중심** (기준 좌표는 실제 장소 확인 후 설정)
- 내 위치 버튼: **누를 때만** 위치 권한 요청
- 마커 카드: 포스터 · 배지 · 제목 · 기간·장소·구 · 상세 보기 · 길찾기 · ♡. **좌우 스와이프**, 순서 = 현재 카드에서 **가까운 순**, 넘기면 지도도 해당 마커로 이동. 위에 "가까운 순 · 1 / N"
- 하단 바 "검색 결과 N개 · 목록 보기 ⌃": **바 전체가 버튼** + 위로 끌어올리기로 목록 열림

### 03 길찾기 창 (하단 시트)
- 행사명 · 장소명 · 주소 + **주소 복사**
- 카카오맵 · 네이버 지도 · **Google Maps** (보조 문구 "대중교통 길찾기만 지원(도보·자동차 미지원)" — 한국 정밀지도 사정, 외국인용)
- "앱이 설치되어 있지 않으면 웹 지도가 열려요" · 취소
- 각 지도 앱은 URL 링크로 열기 (API 키 불필요한 방식)

### 04 상세
- 상단: 뒤로 · 공유(링크 복사 → 토스트) · ♡
- 포스터 300px → 분류 · 구 → 제목 22px → 상태 배지 + "종료까지 D-N"
- **고정 탭: 정보 | 주변** (스크롤해도 상단에 붙음)
- 정보: 기간 · 시간 · 장소 · 요금 (라벨 56px + 값 2열). API 원문을 칸별로 나누는 작업은 별도(아래 "나중에")
- 소개: 3줄 + 더보기
- 위치: 작은 지도 + 주소 + 주소 복사
- 하단 고정: ♡ 버튼 + "길찾기"(→ 03)

### 05 찜 (빈 상태)
- 탭: 찜 N | 최근 본 N
- 비었을 때: 하트 아이콘 · "아직 찜한 행사가 없어요" · 안내 · "행사 둘러보기" 버튼(→ 홈)
- 정적 버전 = 브라우저 저장(localStorage). Spring Boot 버전(11/4 · 11/9 결정): **찜 = 서버 찜(FavoriteService, 로그인 회원)** 그대로, **최근 본 = 상세를 연 행사를 브라우저 저장(localStorage)** — 로그인 없이, 서버로 보내지 않음 (`static/recent-views.js`)

### 06 검색 · 입력 중 (자동완성)
- 글자만 있는 행(높이 56px), **사진 없음** (입력할 때마다 이미지가 깜빡이는 문제 방지)
- 맨 위: 검색어가 구 이름과 맞으면 "📍 팔달구 · 지도에서 행사 N개" 행 → 지도 + 구 필터
- 행: `[상태 배지(폭 고정)] 제목(검색어 accent 강조, 한 줄 말줄임) … 구`
- 정렬: 운영중 · 오픈예정 먼저, 종료는 맨 아래

### 07 검색 결과 (엔터 후)
- "검색 결과 N개" + 정렬(종료 임박순)
- 행사 행(포스터 56×70 왼쪽) + 배지 + D-day + ♡

- 검색 0건 안내, 필터 시트, 캘린더(목록 탭) → 2단계
