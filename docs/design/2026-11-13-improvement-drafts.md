## P1 PC 지도 · 하단 카드

- **오른쪽 목록 칸은 지금 배치 그대로** (탭 [진행 중 N · 진행 예정 N · 달력 ▾], 접기 버튼 포함). 지도가 넓어지지 않게 유지
- **카드 3장을 지도 영역(목록 칸 뺀 너비) 가운데 정렬**, 양옆에 원형 ‹ › 버튼(40px, `--text` 바탕 · 흰 글자). 지도 영역이 좁아 3장이 안 들어가면 2장
  - 카드 폭 약 262px, 사진 60×84, 높이 약 196px. 고른 카드는 2px `--text` 테두리
- **카드 내용** (위에서 아래로)
  1. 배지: `진행 중`(`--accent` 바탕 흰 글자) + `종료까지 D-37` 또는 `오픈 예정`(`--blue-soft`/`--blue`) + `D-2`(`--accent-soft`/`--accent-ink`)
  2. 제목 15~16px 굵게, 최대 2줄
  3. 기간 줄: 달력 아이콘 + `08.01 – 12.19 · 주말` (14px, `--text`)
  4. 장소 줄: 핀 아이콘 + `정조테마공연장 · 팔달구` (14px)
  5. [상세 보기] [길찾기]
  - 지금의 '같은 장소 1/6 · 기간 · 장소' 한 줄은 없앤다
- **같은 장소 표시는 카드 밖**: 카드 줄 위 가운데 검은 띠 `이 장소 행사 1 / 6 · 정조테마공연장` (13px, `--text` 바탕 흰 글자, 장소명은 `#a9a39b`)
- **마커 움직임** (같은 장소 다음 카드로 넘길 때): 0.2초에 위로 + 1.2배, 0.4초에 제자리 + 벽돌색 35% 고리가 한 번 퍼짐. `prefers-reduced-motion` 이면 생략. 사용자: "해 보고 수정"
- **키보드** (카드 줄에 포커스가 있을 때만): Enter = 상세 열기, Space = 찜/해제(페이지 스크롤 막음), ← → = 이전/다음 카드, Esc = 상세 닫기(지금도 됨). 카드 줄 아래 작은 안내 `Enter 상세 · Space 찜 · ← → 넘기기` (11px, `--sub`)
- **PC 길찾기 창** (지금 레이아웃 깨짐 → 고침): [길찾기] 버튼 위에 뜨는 300px 작은 창. 제목 `길찾기` + 닫기 ×, 주소 회색 칸(`--surface`), [카카오맵에서 길찾기] [네이버 지도에서 길찾기] (높이 40px, 테두리), `주소 복사` 글자 버튼. 열려 있는 동안 버튼은 `길찾기 ▴`. 모바일 바텀시트는 그대로

## P5 닉네임 · 마이페이지 로그아웃 (L — 메인이 직접)

- 가입할 때 랜덤 닉네임: **형용사 30개 × 수원 랜드마크 30개 = 900가지** (예: `푸르스름한 화성행궁`). 이미 있으면 끝에 숫자 2자리
- 마이페이지에서 수정: 2~12자, 한글 · 영문 · 숫자 · 띄어쓰기, 다른 회원과 겹치면 안 됨(DB 유니크). 다시 뽑기 버튼(↻)
- 마이페이지 카드: 첫 글자 동그라미 + 닉네임 + `회원 #3`, 닉네임 입력칸 · 저장, 연동 계정, **[로그아웃]**(테두리 버튼), 아래 서비스 안내 · 개인정보 처리방침 · 회원 탈퇴
- 단어 목록은 PR 에 표로 넣어 사용자가 고칠 수 있게
