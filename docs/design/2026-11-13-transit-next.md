## ① 모바일 주변 탭 (모바일 A)

- 순서 그대로: 위치 제목 → 작은 지도 → 주소 박스(주소 + [주소 복사], **길찾기 버튼 넣지 않음**) → 가까운 정류장 → 가까운 역 → 출처 한 줄
- **새로**: 출처 줄 아래, 탭 맨 아래에 전폭 버튼 "길찾기 (대중교통)"
  - 높이 48px, 테두리 1px `--accent`, 바탕 `--bg`, 글자 `--accent` 15px 굵게, 모서리 6px (하단 고정 바의 채운 [길찾기] 와 구분되게 테두리형)
  - 누르면 지금 하단 고정 [길찾기] 와 같은 하단 창 `#routeSheet` 를 엶 (새 동작 없음)
  - 정류장 · 역 칸이 숨겨져도(불러오기 실패 등) 버튼은 보임
- 하단 고정 [☆ 찜] [길찾기] 바는 그대로

## ② PC 상세 칸 (PC A, 폭 440px)

- 자리: 버튼 줄([☆ 찜] [길찾기] [원문 ↗]) **아래**, 위 선 1px `--line` + 위 여백 14px, 제목 "오시는 길" 15px 굵게. **늘 펼침** (접기 없음 — 상세 칸이 `#pcdScroll` 안에서 따로 스크롤되므로 모니터가 낮으면 아래로 밀릴 뿐, 포스터 · 정보 · 버튼 자리는 그대로)
- 정류장: **2칸 격자**(`repeat(2, minmax(0, 1fr))`, 간격 10px), 칸마다 테두리 1px `--line` · 모서리 6px · 안쪽 10px
  - 위에서부터: "정류장" 12px `--sub` → 이름 14px 굵게 → "도보 N분 · Nm" 12px `--sub` → 버스 번호 칩(12px, 테두리 1px `--line`, 모서리 4px)
  - 칸이 좁아 칩은 **4개 + "+N"** (모바일은 6개 그대로). "+N" 누르면 그 칸의 나머지 칩을 펼침 (모바일과 같은 동작)
  - 정류장이 1곳이면 1칸만 (빈 칸 없음)
- 역: 정류장 아래 한 줄 박스(바탕 `--surface`, 모서리 6px, 안쪽 10px): 왼쪽 "역 이름 + 호선(보조색)", 오른쪽 "직선 N.Nkm" 13px `--sub`
- 출처 한 줄: 모바일과 같은 문구 12px `--sub`
- 데이터: 모바일과 같은 `GET /api/events/{id}/transit` (`transit-nearby.js` 의 글자 만들기 함수를 PC 모양으로 나눠 쓰거나 PC 용 함수 추가). 행사를 넘길 때(‹ ›) 다시 불러옴, 늦게 온 이전 행사 응답은 버림
- 불러오기 실패 · 정류장도 역도 없음 → 칸 전체 숨김 (모바일과 같음)

### 장소 줄 누르면 주소 복사 (PC 만)

- 정보 표(`#pcdRows`) "장소" 값을 `<button>` 으로: 글자 아래 점선 1px `--line-strong`, 오른쪽에 복사 아이콘(선 아이콘 14px, `--sub`), 마우스 올리면 `title` "누르면 주소 복사", 커서 `copy`
- `aria-label` = "주소 복사: <장소 · 주소>"
- 누르면 주소를 클립보드에 복사 → 오른쪽에 작은 "복사됨" 표시(바탕 `--text`, 글자 `--bg`, 11px, 모서리 4px) **1.5초** 뒤 사라짐
- 복사할 값 = 모바일 [주소 복사] 와 같은 주소 (`extractAddress` 결과, 없으면 장소 글자)
