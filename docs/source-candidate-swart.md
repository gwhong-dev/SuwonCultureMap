## 4. 확인할 것 (사용자 PC)

**① CSV 내용 · 오픈API 여부**
1. 브라우저에서 `https://www.data.go.kr/data/15148747/fileData.do` 열기
2. "미리보기" 또는 다운로드 → **공연 날짜 범위**(지난 공연만? 다음 해 일정도?) · 행 수 · 날짜 형식 · 구분 값 종류 확인 → 이 문서 1번에 적기
   - 되어 있나요? → 올해 지난 공연만이면 **다가올 공연용으로는 쓸모없음** (결론 그대로)
3. 같은 페이지에 "오픈API" 탭이 있는지 확인 (data.go.kr 이 CSV 를 API 로 바꿔 주는 경우가 있음)

**② 공식 사이트**
1. `https://art.suwon.go.kr/robots.txt` 를 브라우저로 열어 `Disallow` 줄 확인
2. 공식 사이트 공연 일정 화면에 **RSS 아이콘 · "오픈API" 메뉴** 가 있는지 확인
   - 있으면 → 이 문서 1번 표 ③ 을 고쳐 다시 검토 / 없으면 → 결론 그대로 (크롤링은 하지 않음)

**③ 빠진 공연이 있는지** (Claude 가 할 수 있음, 필요할 때)
- CSV 의 다가올 공연 목록 ↔ 운영 `/api/events` 를 합치기 기준으로 비교 → 빠진 공연이 **분기에 2건 이상**이면 3번 작업(M)을 다시 검토

## 5. 결론

- **넣지 않음.** 예술단 공연은 재단 · 인스타로 이미 지도에 있고, 따로 받을 수 있는 공식 길은 연간 CSV(좌표 · 이미지 · 링크 없음)뿐
- 크롤링(공식 사이트)은 robots 차단 · 이용 조건 ❓ 이라 하지 않음
- 대신: 인스타 공식 계정에 예술단 계정이 따로 있으면 그 계정을 인스타 수집 목록에 더하는 쪽이 싸고 같은 효과 ❓ (예술단 계정 유무 확인 필요. 운영 수집 계정 목록은 환경변수 `INSTAGRAM_ACCOUNTS` 라 저장소에서 안 보임 — 지금 5계정에 이미 있는지 먼저 확인)
