# 인스타 "관광 대상 아님" 거르기 (2026-11-13)

## 문제
- 시청 계정(suwon_city)은 정책 포럼 · 기념식 · 기업 박람회도 행사와 같은 모양(제목 + 🗓️ + 📍)으로 올림
- `RuleCaptionParser` 는 이 세 줄만 있으면 행사로 판정 → 운영 지도에 「제12회 교통정책발전포럼」(수원시청 중회의실, id 231) 같은 글이 올라감
- 예전에 READY 였던 블록이 나중에 READY 가 아니게 돼도 행사 연결을 남겨 두는 구조 → 규칙만 넣으면 이미 올라간 행사는 그대로 남음

## 구현
- `NonTouristFilter` (caption) — 낱말 판정
- `CaptionParser.checked` — 규칙 · AI 결과 모두 PARSED · NO_DATE 면 검사 → SKIPPED. **읽은 값(event)은 남김**: 블록 키(제목 + 시작일 + 장소)가 READY 때와 같아야 예전 블록을 찾음
- `ExpiredInstagramEventCleaner.cleanNonTourist` — 동기화 끝(지난 행사 정리 다음, 사진 정리 전)에 인스타 행사 전체를 다시 봄. 찜 있으면 남김, 숨김 해제 → 진행 날짜 → 블록 SKIPPED · 끊기 → 삭제
- `InstagramPostProcessor` SKIPPED 처리 — 이유가 "관광 대상 아님"이고 블록에 행사가 있으면 `StaleBlockRetirer.dropNonTourist` 로 행사 삭제 (숨김 해제 → 블록 끊기 → 삭제, 진행 날짜는 FK CASCADE, 사진은 동기화 끝 사진 정리가 지움)

## 버린 안
- 제목 낱말만 넣고 기존 행사는 종료 7일 뒤 자동 삭제까지 둠 → 231 · 196 · 197 이 지도에 며칠 더 남음
- 운영 DB 에서 바로 삭제 → 되돌리기 어렵고, 규칙이 없으면 다음 동기화에 다시 생김
- "박람회" 전체 거르기 → 커피 · 애견용품 박람회처럼 지도에 있을 만한 행사까지 빠짐
- 일반 "강연 · 교육" 전체 거르기 → 이번 결정 범위 밖 (새빛포럼은 "포럼"으로 걸림)
