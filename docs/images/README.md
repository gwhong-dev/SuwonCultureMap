# docs/images — 포트폴리오 · 노션용 캡처

claude.ai 채팅이 노션 "문제 → 해결" · 포트폴리오를 만들 때 읽는 화면 캡처를 둔다 (규칙: `CLAUDE.md` 4-1).

- 파일 이름: `YYYY-MM-DD-주제.png` (예: `2026-11-12-calendar-strip.png`)
- 고른 것만 넣는다. 작업 중 확인용 캡처는 PR 댓글에만
- 장당 300KB 이하
- **이 저장소는 공개** → 이메일 · 이름 · 토큰 · 주소창 `code=` · 관리자 화면 · 개발자 도구가 보이면 가리거나 넣지 않는다
- 캡처를 넣은 PR 의 작업 기록 줄(`PROGRESS-LOG.md` "🧾 작업 기록")에 파일 이름을 적는다
