# 유사 앱 벤치마킹 — 레이아웃 · 페이지 구조

> 작성일: 2026-11-02
> 목적: 모바일 화면을 "웹을 줄인 화면"이 아니라 **앱식 레이아웃**으로 바꾸기 위해, 상용 앱 4개의 구조를 비교하고 적용 우선순위를 정함
> 원본 캡처: 노션 "수원문화지도 > 유사어플 레이아웃 및 기능" (개인정보가 보이는 캡처가 있어 저장소에는 올리지 않음)

## 0. 분류 기준

| 표시 | 뜻 |
|---|---|
| 🟢 가져올 것 | 구조를 그대로 써도 좋음 |
| 🔵 더 좋게 가져올 것 | 아이디어는 좋은데 아쉬운 점을 고쳐서 적용 |
| ⚪ 안 가져올 것 | 우리 서비스에 안 맞거나 단점 |

등급: **S** = 작은 수정 / **M** = 화면 1개 또는 기능 1개 / **L** = 백엔드까지 바뀌는 큰 작업

## 1. 앱별 요약

| 앱 | 하단 탭 | 특징 |
|---|---|---|
| 헤이팝 | 홈 · 지도 · 검색 · 찜 · 마이 | 썸네일 마커 + 숫자 클러스터, 비로그인 둘러보기 자유, 지도 앱 바로가기 |
| 팝가 | 홈 · 발견 · 내 주변 · 찜 · 마이 | 필터 시트 + "48곳 보기" 결과 수 미리 표시, 운영중/오픈예정 배지, 지도↔목록 토글 |
| 프레젬 | 홈 · 피드 · 지도 · 지갑 · 프로필 | 상세 "종료까지 D-23", 근처 장소 거리(km) |
| 팝플리 | 발견 · 관심 · 내주변 · 캘린더 · 마이플리 | 날짜 칩(오늘·+7일·+2주), 주간 캘린더, 상세 고정 탭, AI 요약, 주변 핫플(도보 m) |

---

## 2. 4개 앱 공통점

1. **하단 탭 5개**: 홈 / 탐색 / 지도 / 찜 / 마이
2. **마커 클릭 → 하단 카드** (사진 · 이름 · 기간 · ♡ · 길찾기)
3. **길찾기 → 지도 앱 선택** (네이버 · 카카오 · 구글/T맵) + 주소 복사
4. **상태 표시**: D-day, 운영중 · 오픈예정 · 종료
5. **카테고리 칩** (누르면 바로 걸러짐)
6. **소셜 로그인**, 카카오 버튼이 맨 위

3개 앱 공통: 근처 추천(거리 표시), 공유 링크 복사, 찜 토스트

## 3. 우리 페이지 구조 (안)

```
하단 탭: 홈 | 지도 | 목록(캘린더) | 찜
(정적 버전은 로그인 없음 → 마이 탭 제외. Spring Boot 버전은 마이 탭 추가)

홈
├─ "이번 주 수원 행사 N개"
├─ 포스터 캐러셀: 이번 주 주요 행사 5개
├─ 빠른 날짜 칩: 오늘 · 이번 주말 · +7일
├─ 이달의 수원 행사 (가로 카드)
├─ 곧 종료 / 곧 시작 (D-day 배지)
└─ 내 주변: 가까운 · 장안 · 권선 · 팔달 · 영통 칩 + 작은 지도

지도
├─ 상단: 검색창 + 카테고리 칩 + 필터 버튼
├─ 마커(포스터 썸네일) / 줌아웃 시 숫자 클러스터
├─ 마커 클릭 → 하단 카드
├─ 하단 시트 "검색 결과 N개 · 목록 보기"
└─ 내 위치 버튼(누를 때만 위치 권한 요청) · 이 지역 다시 찾기

목록 / 캘린더
├─ 주간 달력 → 선택한 날짜의 행사 목록 "11월 2일 · N개"
├─ 필터 시트(분류 · 구 · 상태) + "N곳 보기" 버튼
├─ 적용된 필터 칩(✕) + 초기화, 정렬(종료 임박순 · 최신순)
└─ 0건이면 안내 문구 + 추천 행사

상세
├─ 포스터 · 분류 · 제목 · 기간 · D-day · 상태 배지
├─ ♡ 찜 · 공유(링크 복사 → 토스트)
├─ 고정 탭: 정보 | 주변
├─ 정보: 편의 아이콘(무료 등) · 시간 · 설명(접기/더보기)
├─ 작은 지도 + 주소 복사 + 길찾기(카카오 · 네이버)
└─ 근처 행사 (거리 표시)

찜
├─ 찜 · 최근 본 (브라우저 저장, 로그인 불필요)
└─ 비어 있으면 안내 + "행사 둘러보기" 버튼
```

## 4. 적용 우선순위

### 🥇 1단계: 뼈대 (모바일 앱식 레이아웃)

| 항목 | 등급 | 근거 |
|---|---|---|
| 하단 탭: 홈 · 지도 · 목록 · 찜 | M | 4개 앱 공통 |
| 마커 클릭 → 하단 카드 | M | 4개 앱 공통 |
| 지도 하단 시트 "검색 결과 N개" | S | 헤이팝 · 팝플리 |
| 길찾기 창 (주소 복사 · 카카오 · 네이버) | S | 4개 앱 공통 |
| 상태 배지(운영중 · 오픈예정 · 종료) + D-day | S | 날짜만으로 계산 가능 |
| 찜 토스트 | S | 3개 앱 |
| 스켈레톤 로딩 | S | 팝플리 |

### 🥈 2단계: 찾기 편하게

| 항목 | 등급 | 근거 |
|---|---|---|
| 필터 시트 (분류 · 구 · 상태) + "N곳 보기" | M | 팝가 |
| 적용된 필터 칩 + 초기화, "N곳" + 정렬 | S | 팝가 |
| 빠른 날짜 칩: 오늘 · 이번 주말 · +7일 | S | 팝가 · 팝플리 |
| 지역 칩: 수원 4개 구 | S | 주소에서 구 추출 가능 여부 확인 필요 |
| **캘린더**: 주간 달력 + 날짜별 목록 | M | 팝플리. 문화행사는 날짜로 찾는 경우가 많음 |
| 상세: 고정 탭 · 접기/더보기 · 작은 지도 · 공유 | M | 팝플리 · 프레젬 |
| 상세 아래 근처 행사 (거리) | M | 3개 앱 |
| 검색 0건 안내 문구 | S | 헤이팝에 없어서 아쉬웠던 부분 |
| 내 위치 버튼 · 이 지역 다시 찾기 | S~M | 프레젬 · 팝플리 |

### 🥉 3단계: 우리 서비스에 맞게 더 좋게

| 항목 | 등급 | 메모 |
|---|---|---|
| 홈 "이번 주 수원 행사 N개" + 포스터 캐러셀 | M | 팝플리 |
| 이달의 수원 행사 (월 자동) | S | 팝플리의 "담당자 추천"을 날짜 기반으로 |
| 검색 자동완성 (상태 배지 + 구 표시) | M | 팝플리 |
| 추천 키워드 칩 (공연 · 전시 · 축제 · 무료 · 어린이) | S | API 분류값 확인 필요 |
| 편의 아이콘 (입장료 무료 등) | S~M | API에 요금 칸이 있는지 확인 필요 |
| 지도 마커에 포스터 썸네일 | M | 헤이팝 · 팝플리 |
| 최근 본 행사 (localStorage) | S | 로그인 없이 가능 |
| 행사 제보하기 | M | 팝플리 "팝업 제보". 나중에 업체 홍보 등록과 연결 가능 |
| **AI 요약** (동기화 시 1회 생성 → DB 저장) | L | 팝플리. 포트폴리오 목표("AI 워크플로우 활용")와 연결 |
| 코스 만들기 (행사 + 주변 맛집) | L | 팝플리. 나중에 |

## 5. 안 가져올 것 (⚪)

| 항목 | 이유 |
|---|---|
| 앱 진입 즉시 위치 · 알림 권한 요청 | 4개 중 3개가 그렇게 함 → **우리는 버튼을 누를 때만** 요청 (차별점) |
| 진입 시 로그인 팝업, 가입 도중 관심사 · 생년월일 · 성별 입력 | 둘러보기를 방해함 |
| 확인 버튼을 눌러야 닫히는 "링크 복사됨" 창 | 토스트로 대체 |
| 화면을 가리는 큰 맨 위로 버튼 | 작게 만들거나 목록 화면에만 표시 |
| 계절 장식 (지도 · 버튼을 가리는 낙엽) | 가독성 저하 |
| 해시태그 칩 10개 이상 | 3~4개만 표시 |
| 원문(한글 + 영어) 그대로 붙인 안내문 | 기간 · 시간 · 요금 항목으로 정리 |
| 포인트 · 지갑 · 피드 · 예약 · 굿즈 · 친구 초대 · 회원 등급 | 판매 · 커뮤니티 기능, 공공 데이터 조회 서비스와 무관 |
| 후기 · "다른 회원이 함께 본" · 블로그 반응 | 로그인 · 사용 데이터가 필요해 지금은 제외 |

## 6. 확인이 필요한 API 항목

- [ ] 분류(공연 · 전시 · 축제 등) 필드 → 카테고리 칩 · 추천 키워드
- [ ] 주소에서 구(장안 · 권선 · 팔달 · 영통) 추출 가능 여부 → 지역 칩
- [x] 요금 / 무료 여부 필드 → 편의 아이콘 · "무료" 칩 (11/9 V7 `fee` + 지도 칩 "💸 무료")
- [ ] 대상(어린이 등) 필드 → "어린이" 칩 — 확인 결과(11/9) 재단 "대상" 칸 1건뿐 → 보류
- [ ] 이미지 여러 장 여부 → 상세 캐러셀
