개인정보 처리방침

수원바이블(이하 "서비스")는 수원문화재단 등 행사 정보 제공 기관과 무관한 비공식 개인 운영 서비스입니다. 서비스는 회원과 문의하는 분의 개인정보를 아래와 같이 처리합니다. 지도 보기와 행사 조회는 로그인 없이 이용할 수 있습니다.

1. 처리하는 개인정보 항목과 목적

대상 항목 목적
소셜 로그인 회원 로그인 제공자(카카오·구글·네이버), 제공자의 회원 식별값, 가입 시각 같은 소셜 계정 확인, 소셜 계정 연동, 찜 목록 유지, 탈퇴 처리
찜 기능 이용 회원 찜한 행사, 찜한 시각 찜 목록 제공
이용자 세션 쿠키(접속 중 로그인 상태와 로그인 보안값 유지) 로그인 상태 유지, 로그인 위조 방지
이메일로 문의·요청하는 분 보낸 사람 이메일 주소, 메일 내용(회원 번호 등 직접 적은 정보 포함) 문의 답변, 권리 행사·삭제 요청 처리와 결과 안내

로그인은 소셜 서비스에 맡기며 서비스는 로그인할 때 이름, 이메일, 비밀번호를 저장하지 않습니다. 소셜 로그인 토큰은 로그인 처리에만 쓰고 저장하지 않습니다. 제공자가 동의 범위에 따라 다른 정보를 함께 보내더라도 서비스는 위 항목만 저장합니다.

2. 처리 및 보유 기간

회원 정보와 찜 기록은 회원 탈퇴 시까지 보유합니다. 세션 쿠키는 로그아웃하거나, 브라우저를 닫거나, 일정 시간 이용하지 않으면 효력이 사라집니다. 문의 메일은 처리를 마칠 때까지 보유합니다.

3. 파기 절차와 방법

회원이 마이페이지에서 탈퇴하면 회원 정보, 로그인 수단, 찜 기록을 서비스 데이터베이스에서 즉시 삭제합니다. 문의 메일은 처리를 마친 뒤 지체 없이 메일함에서 삭제합니다. 시스템 복구용 백업: 서비스 데이터베이스 전체를 매일 서버에 백업하고, 백업 파일은 14일이 지나면 삭제합니다. 운영자 PC에 복사한 사본도 14일 안에 삭제합니다. 따라서 탈퇴한 회원의 정보가 백업에 최대 14일 남을 수 있습니다. 법령에 따라 별도로 보존하는 개인정보는 없습니다.

4. 제3자 제공

법령에 근거가 있는 경우를 제외하고 회원의 개인정보를 제3자에게 제공하지 않습니다.

5. 처리 위탁과 국외 이전

서비스는 개인정보 처리 업무를 아래와 같이 위탁합니다.

수탁 업체위탁 업무처리 위치
Amazon Web Services서버 · 데이터베이스 운영대한민국(서울 리전)
Cloudflare, Inc.문의 메일 전달, 도메인 이름 관리미국 등 업체의 해외 서버
Google LLC (Gmail)문의 메일 수신 · 보관미국 등 업체의 해외 서버

국외 이전: 회원 정보와 찜 기록은 대한민국 서버에 저장하며 국외로 이전하지 않습니다. 문의 메일을 보내면 보낸 사람의 메일 주소와 메일 내용이 수신 시점에 네트워크를 통해 Cloudflare(미국)를 거쳐 Google(미국)로 이전되고, 처리를 마칠 때까지 보관한 뒤 삭제합니다. 메일을 보내지 않으면 이전되지 않습니다. 이전을 원하지 않으면 메일을 보내지 않으면 되며, 이 경우 메일 문의는 이용할 수 없습니다. 업체 연락처: Cloudflare 개인정보 정책, Google 개인정보처리방침.

접속 기록: 방문 기록을 별도로 저장하지 않습니다. 다만 서버 오류가 나면 오류 로그에 접속 IP 등이 남을 수 있으며, 로그는 용량 제한에 따라 오래된 것부터 자동으로 삭제됩니다.

6. 외부 서비스로 전송되는 정보

  • 소셜 로그인: 로그인할 때 카카오·구글·네이버에서 회원 식별값과 동의 범위의 정보를 전달받으며, 식별값 외의 정보는 저장하지 않습니다. 탈퇴할 때는 연결 해제를 위해 카카오 회원번호를 카카오에 보냅니다. 각 사의 처리는 해당 사의 방침을 따릅니다.
  • 카카오 지도: 지도를 표시하기 위해 이용자의 브라우저가 카카오 서버에 접속하며, 이때 IP 주소 등 접속 정보가 카카오에 전달될 수 있습니다.
  • 행사 이미지: 행사 이미지를 표시할 때 브라우저가 이미지를 제공하는 서버(수원문화재단 등)에 접속할 수 있습니다.

7. 이용자의 권리와 행사 방법

이용자와 법정대리인은 이용자의 개인정보에 대해 열람, 정정, 삭제, 처리정지를 요구할 수 있으며, 법정대리인은 아래 연락처로 대리 요청할 수 있습니다. 회원 탈퇴는 마이페이지에서 직접 할 수 있고, 그 밖의 요구는 아래 연락처로 보내 주시면 확인 후 법령이 정한 기간 안에 처리하고 결과를 알립니다. 회원 정보에는 이메일이 없으므로, 요청할 때 마이페이지의 회원 번호를 함께 보내 주세요. 본인 확인을 위해 소셜 로그인을 요청할 수 있으며, 소셜 계정으로 로그인할 수 없으면 대상을 특정하지 못해 처리가 제한될 수 있습니다. 이용자는 자신의 개인정보를 정확하게 유지하고, 다른 사람의 정보를 침해하지 않아야 합니다.

탈퇴할 때 카카오 연결 해제를 함께 요청합니다. 해제에 실패하면 화면에 안내하며, 이 경우 카카오계정 설정에서 직접 해제할 수 있습니다. 구글·네이버의 앱 연결은 서버에서 해제하지 않으므로 각 계정 설정에서 직접 해제할 수 있습니다.

8. 자동 수집 장치

로그인 상태 유지를 위해 세션 쿠키를 사용하며, 로그인하지 않은 방문자에게도 발급될 수 있습니다. 서비스 자체는 방문 통계나 광고용 쿠키를 사용하지 않습니다. 카카오 지도의 처리는 카카오의 방침을 따릅니다. 브라우저 설정에서 쿠키를 거부할 수 있으나, 거부하면 로그인과 찜 기능을 이용할 수 없습니다.

찜 탭의 "최근 본" 목록을 위해 상세를 연 행사 번호(최대 20개)를 이용자 기기의 브라우저 저장소(localStorage)에만 저장하며, 서버로 보내지 않습니다. "최근 본" 목록의 "모두 지우기"나 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

9. 안전성 확보 조치

  • 로그인 때 위조 방지값을 확인하고, 로그인 성공 시 세션 ID를 교체합니다.
  • 클라이언트 시크릿, 관리자 키, 데이터베이스 비밀번호 등 비밀값은 코드 저장소에 넣지 않고 별도로 관리합니다. 브라우저에 공개되는 지도 키는 제외합니다.
  • 소셜 로그인 토큰은 사용 후 저장하지 않습니다.
  • 사이트와의 통신을 HTTPS로 암호화합니다.
  • 데이터베이스는 외부에서 접속할 수 없게 막고, 서버 관리 접속은 운영자에게만 허용합니다.
  • 클라우드 관리 계정에 2단계 인증을 적용합니다.

10. 행사 정보의 출처별 처리와 삭제 요청

출처 상태 처리 내용
수원문화재단 공개 API 사용 중 행사 제목, 분류, 일시, 시간, 장소, 설명, 이미지 주소, 원문 링크, 좌표를 받아 저장하고 지도에 표시합니다.
공개 인스타그램 게시물 (Meta 공식 API) 사용 중 (수원시·문화기관 공식 계정만) 수원시·문화기관 공식 계정 게시물의 ID, 계정 이름, 링크, 게시 시각, 캡션을 받아 캡션에서 뽑은 행사 제목, 분류, 일시, 시간, 장소를 게시물 ID, 계정 이름, 링크, 게시 시각, 처리 상태, 좌표와 함께 저장하고 지도에 표시합니다. 캡션 전체는 데이터베이스에 저장하지 않고 사진은 받지 않습니다. 개인 계정의 게시물은 수집하지 않습니다. 삭제한 내용은 백업에 최대 14일 남을 수 있고, 처리 기록에 남은 행사 제목·장소 일부(각 40자 이내)는 서버 로그가 자동으로 삭제될 때까지 남을 수 있습니다. 인스타그램에서 받은 정보는 판매하거나 광고에 쓰지 않습니다.

삭제 요청: 게시물 작성자나 권리자가 표시 중단이나 삭제를 원하면 게시물 링크나 행사 이름을 적어 contact@suwonbible.com 으로 보내 주세요. 확인 후 지체 없이 삭제합니다. Meta(인스타그램) 앱을 통해 받은 데이터의 삭제 요청도 같은 방법으로 받습니다.

11. 만 14세 미만 아동

회원 서비스는 만 14세 이상을 대상으로 하며, 가입할 때 나이를 확인하지는 않습니다. 만 14세 미만 아동은 로그인 없이 지도를 이용해 주세요. 법정대리인 동의 없이 만 14세 미만 아동의 정보가 수집된 것을 알게 되면 지체 없이 삭제합니다.
